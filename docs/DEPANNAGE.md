# Dépannage

## Chrome ne trouve pas manifest.json

Sélectionnez le sous-dossier **extension** du dossier décompressé. Le fichier `manifest.json` doit se trouver directement dans le dossier que vous choisissez. Le ZIP lui-même ne se sélectionne pas dans **Charger l’extension non empaquetée**.

## Le bouton PHAROS ne s’affiche pas

Rechargez l’onglet Facebook après l’installation ou l’actualisation de l’extension. Vérifiez dans `chrome://extensions` que PHAROS Compagnon est activé. Ouvrez le commentaire ou développez les réponses.

Si l’interface n’est pas reconnue, sélectionnez le texte et utilisez le menu contextuel **Préparer un signalement PHAROS avec cette sélection**. Vous pouvez aussi ouvrir **Mes dossiers** et créer une fiche manuelle.

## Le nom ou le lien est absent

Vérifiez les informations et complétez le champ dans la fiche. Un lien vers le profil de l’auteur ne remplace pas le lien du commentaire ou de la publication. Sur Facebook, le lien associé à la date du commentaire peut aider à retrouver son adresse.

Un ancien relevé reste conservé comme origine de la fiche. Vous pouvez corriger le brouillon ou effectuer une nouvelle collecte si de meilleures informations sont disponibles.

## La capture ne fonctionne pas

Revenez sur l’onglet Facebook où vous venez de collecter le commentaire. Placez le commentaire à l’écran et ouvrez le bouton de l’extension pour déclencher **Capturer la page visible**. Vous pouvez aussi joindre un fichier PNG ou JPEG depuis la fiche.

## PHAROS ne remplit pas un champ

Vérifiez les liens, le texte, la catégorie, la visibilité publique et le choix Oui ou Non relatif à la qualité de victime. Le préremplissage dépend de la reconnaissance des champs du portail et le brouillon temporaire expire après trente minutes.

Rouvrez PHAROS depuis la fiche si nécessaire. Le panneau propose également la copie du lien et de la description. Les coordonnées, les contrôles du portail et la confirmation finale se complètent manuellement.

## La liste de dossiers décale le formulaire

Vérifiez que la version installée est **1.0.3**, actualisez l’extension puis rechargez l’onglet **Mes dossiers**. Le correctif sépare le défilement de la liste et du formulaire sur ordinateur. Sur écran étroit, les colonnes peuvent être empilées.

## Les dossiers semblent absents après une nouvelle installation

Vérifiez le profil Chrome et l’installation utilisée. Une nouvelle installation peut avoir un stockage distinct. Si vous disposez d’une sauvegarde JSON, utilisez **Importer**. L’éditeur ne possède pas de copie centrale de vos dossiers.

## Signaler un problème technique

Ouvrez une **Issue** avec un titre précis, les versions de Chrome et de l’extension, le système utilisé, les étapes de reproduction, le résultat attendu et le résultat observé. Utilisez un exemple fictif et anonymisez les captures. Les Issues sont publiques.
